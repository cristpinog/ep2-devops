# Pendientes antes de entregar

## Configuracion externa obligatoria

- [ ] Crear/configurar el proyecto en Snyk y habilitar Snyk Code para la organizacion.
- [ ] Agregar `SNYK_TOKEN` a GitHub Actions secrets.
- [ ] Agregar `SNYK_TOKEN` a Dependabot secrets si se desea validar sus PR automaticamente.
- [ ] Habilitar Dependency graph, Dependabot alerts y security updates.
- [ ] Proteger `main` y exigir los checks del pipeline, incluido `Revision de dependencias del PR`.
- [ ] Ejecutar el workflow desde GitHub y comprobar que queda completamente verde.
- [ ] Descargar o inspeccionar los artefactos de evidencia.
- [ ] Actualizar los enlaces de evidencia en la entrega si el docente los solicita.

## Validacion academica obligatoria

- [ ] Revisar que nombres de integrantes, seccion y formato de entrega esten completos donde corresponda.
- [ ] Revisar y validar personalmente todo contenido generado con IA.
- [ ] Mantener la declaracion y cita de IA del README, ajustada a la norma solicitada.
- [ ] Cada integrante redacta sin IA su propia reflexion y contribucion.
- [ ] El equipo redacta sin IA las conclusiones y justificaciones tecnicas exigidas.
- [ ] Subir el enlace del repositorio al AVA y enviarlo por correo al docente dentro del plazo.

Este archivo enumera tareas; no contiene reflexiones, conclusiones ni justificaciones redactadas por IA.
